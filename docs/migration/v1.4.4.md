# Migration to v1.4.4

From `v1.4.3` to `v1.4.4`.

Updates rust-llm-tidy to action `v2` and its default checks.

## 1. Update `.github/workflows/tidy.yml`

Change the action version and remove the pinned release tag:

```diff
       # Runs my linter.
       - name: Run rust-llm-tidy
-        uses: Sewer56/rust-llm-tidy-action@v1
+        uses: Sewer56/rust-llm-tidy-action@v2
         with:
           mode: apply
           changed-files: "true"
-          release-tag: "0.4.1"
```

## 2. Use the default rust-llm-tidy checks

Remove the explicit `include` block and leave an empty mapping in
`.rust-llm-tidy.yml`:

```diff
 # rust-llm-tidy config.
 #
-# All checks the tool currently supports are listed. New tool release? Add
-# its new checks here; unlisted checks stay off.
-#
-# Upstream references:
-# - Tool's own config: https://github.com/Sewer56/rust-llm-tidy/blob/main/.rust-llm-tidy.yml
+# Upstream reference:
 # - All options: https://github.com/Sewer56/rust-llm-tidy/blob/main/.rust-llm-tidy.example.yml
-
-include:
-  - rules:
-      - tables
-      - fences
-      - links
-      - reorder
-      - vis
-      - DOC001
-      - DOC002
-      - DOC003
-      - DOC004
-      - DOC005
-      - DOC006
-      - TEST001
+{}
```

The `{}` keeps the YAML value as a mapping, so rust-llm-tidy accepts the
file and applies its defaults.

