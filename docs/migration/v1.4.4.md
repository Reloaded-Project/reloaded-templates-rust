# Migration to v1.4.4

From `v1.4.3` to `v1.4.4`.

Updates the rust-llm-tidy workflow to action `v2`, which uses the latest tidy release by default.

## 1. Update `.github/workflows/tidy.yml`

Change the action version and remove the pinned release tag:

```diff
       # Runs my linter.
       - name: Run rust-llm-tidy
-        uses: Sewer56/rust-llm-tidy-action@v1
+        uses: Sewer56/rust-llm-tidy-action@v2
         with:
           mode: apply
           changed-files: "true"
-          release-tag: "0.4.1"
```

## 2. Update the template version marker

```diff
-reloaded-templates-rust:1.4.3
+reloaded-templates-rust:1.4.4
```
