# Migration to v1.4.2

From `v1.4.1` to `v1.4.2`.

Slims the LLM guidance and moves `core`-over-`std` to a Clippy lint:

- Deletes the `.llm/{general,performance,documentation}.md` guidance files.
- Inlines the performance reminders into `src/AGENTS.md`.
- Runs [rust-llm-tidy] at the end of `.llm/verify.{sh,ps1}` when installed.
- Adds the `std_instead_of_core` Clippy lint to the workspace.

## 1. Delete the guidance files

```text
src/.llm/documentation.md
src/.llm/general.md
src/.llm/performance.md
```

## 2. Replace `src/AGENTS.md`

```markdown
After changes, find and run `.llm/verify.{sh,ps1}` to test + lint.
Print all output.

Performance:

- Prefer borrows: `&str` / `&[T]` returns, `&'static str` constants,
  `Cow<'_, str>` for conditional ownership.
- `Box<str>` for immutable strings.
- Reuse buffers via `.clear()`.
- Const generics for compile-time branching such as
  `<const LINE_NUMBERS: bool>`.
- Prefer performance-oriented crates such as `parking_lot` and `memchr`.
- Keep dependency footprint minimal.
```

## 4. Add the Clippy lint

Root `Cargo.toml`:

```diff
 [workspace]
 resolver = "2"
 members = ["src/my-project"]
+
+# Inherited by members via `[lints] workspace = true`.
+[workspace.lints.clippy]
+# Prefer `core` over `std` where both work.
+std_instead_of_core = "warn"
```

Every member crate (`src/my-project/Cargo.toml`, `src/cli/Cargo.toml` if present):

```diff
 # categories = ["command-line-utilities"]
+
+[lints]
+workspace = true
```

Then fix any hits, for example the benchmark:

```diff
-use std::hint::black_box;
+use core::hint::black_box;
```
