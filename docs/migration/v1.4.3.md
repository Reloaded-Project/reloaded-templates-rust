# Migration to v1.4.3

From `v1.4.2` to `v1.4.3`.

Runs the file-altering verify steps first:

- Moves `cargo fmt` and `rust-llm-tidy` to the top of `.llm/verify.{sh,ps1}`.
- Every later step now checks the formatted and tidied files, so a passing run leaves no unverified edits.

